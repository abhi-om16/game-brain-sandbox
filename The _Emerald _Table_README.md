# ♠️ The Emerald Table

*A classic poker experience, built for the browser.*

**The Emerald Table** is a browser-based, Texas Hold’em-inspired poker game where you compete against three computer-controlled opponents using virtual chips. It combines interactive gameplay, poker hand evaluation, and a classic emerald-green table design.

## ✨ Features

- 🃏 Four-player gameplay against three computer opponents
- 💰 Virtual chips and betting actions
- 🎴 Randomized card dealing and community cards
- 🏆 Poker hand evaluation, from High Card to Straight Flush
- 🤖 Computer opponents with randomized decision-making
- 🌿 Custom emerald-green interface with gold accents

## 🛠️ Tech Stack

**HTML · CSS · JavaScript · Python · Streamlit**

## 🎯 Project Highlights

Built to explore game logic, card handling, hand evaluation, player state management, basic AI decision-making, and web deployment.
